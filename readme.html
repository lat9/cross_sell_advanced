What it does

This Zen Cart plugin enables a site to "cross-sell" products. An admin tool is provided that is used to 'connect' the various cross-sells for the site and a simple storefront 'centerbox' is provided for the cross-sells' display. Additional documentation can be found on the plugin's GitHub repository.

Installing and Uninstalling

Starting with v3.0.0, this is released as a Zen Cart encapsulated plugin, so installation (and removal) is simplified.

Installing

  1. Merge the plugin's /zc_plugins directory with your site's pre-existing /zc_plugins directory.
  2. Log into your Zen Cart admin panel.
  3. Use the admin menus, navigating to Modules :: Plugin Manager.
  4. You'll see a plugin named Cross Sell Advanced II; click the Install button for the plugin. That's it!

Installing the Database I/O Manager Handler

Cross Sell Advanced II also provides a DbIo handler to make it easier for you to export and import your site's cross sells. Those files are installed separately and require DbIo v2.2.1 or later for their error-free execution.

Copy the following files to your cart's installation, after renaming the "YOUR_ADMIN" directory to match your custom admin's name:

  1. /YOUR_ADMIN/includes/classes/dbio/DbIoProductsXsellHandler.php
  2. /YOUR_ADMIN/includes/languages/english/dbio/lang.DbIoProductsXsellHandler.php

Uninstall

To uninstall the plugin, navigate to the admin's Modules :: Plugin Manager, find the line-item for Cross Sell Advanced II and click the Un-Install button.
